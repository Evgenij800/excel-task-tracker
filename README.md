# Руководство пользователя: Система управления задачами (Task Tracker)

Добро пожаловать в профессиональный трекер задач в Excel (`tracker.xlsx`)! Эта система разработана для эффективного отслеживания проектных задач, контроля дедлайнов и анализа прогресса команды.

---

## 📂 Структура книги Excel

Книга состоит из трёх взаимосвязанных листов:
1. **`Сводка` (Dashboard)** — аналитическая панель с ключевыми показателями (KPI) и сводными таблицами (количество задач по статусам, категориям и проектам).
2. **`Задачи` (Task Tracker)** — основной реестр задач с демо-данными.
3. **`Справочники` (Dictionaries)** — служебный лист со списками значений для выпадающих списков.

---

## 🛠 Инструкция по использованию

### 1. Работа с основными данными (лист «Задачи»)
* **Добавление задач:** Перейдите на лист **Задачи**, начните ввод следующей задачи в пустой строке под номером 15.
* **Выпадающие списки (Data Validation):**
  * В столбцах **Category**, **Project**, **Responsible Person** и **Status** при клике на ячейку появляется стрелочка выбора.
  * Значения подтягиваются автоматически с листа **Справочники**, что исключает опечатки и ошибки ввода.
* **Автофильтры:**
  * В шапке таблицы (строка 1) включены автофильтры. Нажмите на стрелочку в заголовке любого столбца (например, *Status* или *Project*), чтобы быстро отфильтровать или отсортировать задачи.

### 2. Контроль сроков и статусов (Условное форматирование)
* **Просроченные задачи:** Если наступила дата дедлайна (`Due Date`), а статус задачи **не** равен «Выполнено», ячейка даты автоматически подсвечивается *красным цветом* (`#FADBD8`).
* **Выполненные задачи:** При выборе статуса «Выполнено» ячейка статуса выделяется *зелёным цветом* (`#D4EFDF`).

### 3. Аналитика и Сводка (лист «Сводка»)
* Лист **Сводка** открывается при запуске файла и содержит:
  * **KPI-карточки:** Всего задач, Выполнено, В работе, Просрочено.
  * **Таблицы распределения:** Автоматический подсчёт задач (`COUNTIF`) в разрезе статусов, категорий и проектов.
  * Данные пересчитываются автоматически при изменении записей на листе **Задачи**.

## ⚙️ Системные требования
* Microsoft Excel 2016 / 365, LibreOffice Calc или Google Таблицы.
* Макросы (VBA) не используются, файл полностью безопасен и работает на стандартных формулах и функциях Excel.
